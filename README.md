# Fuhrpark 2.0 – abstract oder virtual?

Startprojekt für die Doppelstunde „abstract oder virtual?“.

`Fahrzeug` ist jetzt eine **abstrakte** Klasse: `Fahren()` ist abstract,
`Hupen()` ist virtual. Was das bedeutet, findest du heute durch
Experimente selbst heraus.

Nach jedem Experiment den Ursprungszustand wiederherstellen:

```
git checkout -- .
```

Im Terminal starten – **im Ordner `Fuhrpark`**:

```
dotnet run
```
